## tela_58 — DEMO11 — iOS e bullets

Arquivo final: `midias/video/demo11.mp4`

Demonstração — Marcador de lista como imagem
O cartão apresenta uma correção para a classe “lista-legada”: criar a imagem do marcador, disponibilizá-la na pasta de mídias e indicá-la na regra CSS. O HTML continua sendo uma lista com seus itens.
ul.lista-legada li {
  list-style-image: url("../midias/imagens/bullet.png");
}
<ul class="lista-legada">
  <li>Primeiro item do conteúdo aprovado.</li>
  <li>Segundo item do conteúdo aprovado.</li>
</ul>
